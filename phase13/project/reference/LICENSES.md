# اعتمادات مشروع توقع المبيعات

أعدت NEXORA CODE ملفات المشروع وبيانات المتجر الخيالية. تحتوي الحزمة التعليمية على الشفرة والبيانات وقائمة الاعتمادات. تُنزّل مكتبات Python من PyPI إلى بيئة المتعلم المحلية، وتضم حزمها نصوص تراخيصها وإشعارات مكوناتها المضمّنة.

الإصدارات التالية مطابقة للحزم المستخدمة عند اختبار المشروع على Windows مع Python 3.14 ‏64-bit. تُعرض تعبيرات التراخيص من بيانات الحزم متى توفرت. طوبقت تراخيص BSD المعلنة دون معرّف محدد مع الشروط الثلاثة في ملفات ترخيص الحزم الفعلية.
