# توقع مبيعات الأسبوع القادم

المشروع يتابع متجرًا افتراضيًا عبر 72 أسبوعًا. يحول كل صف صالح بعد الأسابيع الأربعة الأولى إلى مسألة توقع. يختار بين متوسط مبيعات آخر أربعة أسابيع ونموذج انحدار خطي بناءً على متوسط الخطأ المطلق في أسابيع التحقق.

## التشغيل

افتح PowerShell داخل المجلد الذي يحتوي `forecast.py`. الأوامر مجرّبة على Windows x64 مع Python 3.14.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements.txt
.\.venv\Scripts\python.exe -B -m unittest -v
.\.venv\Scripts\python.exe -B forecast.py --out-dir output --next-promotion 1
```

استخدم مجلد إخراج جديدًا لكل تشغيل. الناتج تقرير بالعربية `report.md` ورسم `predictions.png` وملفا `predictions.csv` و`summary.json`. الرسم يستخدم تسميات إنجليزية للمحاور، ويحتوي الجدول على القيم نفسها للمراجعة. ثبّت المكتبات داخل البيئة الافتراضية محليًا.

## مهمة المتعلم

في نسخة البداية، يفشل اختبار `test_choose_only_lower_error_on_validation` عمدًا. أكمل موضع TODO في `choose_model` داخل `forecast.py`. اختر الانحدار إذا كان خطؤه على التحقق أقل من خطأ المتوسط، واحتفظ بالمتوسط عند التعادل. شغّل الاختبارات مجددًا ثم أنشئ التقرير.

اقرأ الرسم وحدد أسبوعًا أخفق فيه النموذج أكثر من غيره. اذكر عدد الأسابيع مع عرض وبدون عرض قبل المقارنة. اشرح لماذا يظل الخطأ في هذه العينة تقديرًا محدودًا. لا تستنتج أن العرض سبب تغير المبيعات من مقارنة هذه الأخطاء.

## عقد البيانات والتقييم

- الملف `data/weekly_sales.csv` يحتوي أسبوعًا واحدًا لكل يوم اثنين متتالٍ، وعدد وحدات بيعت، ومؤشر عرض معروف قبل بداية الأسبوع.
- لكل أسبوع مستهدف، يحسب البرنامج خصائصه من أسابيعه الأربعة السابقة فقط، ويستخدم عدد وحداته الفعلي لتدريب النموذج وحساب الخطأ بعد انتهاء الأسبوع.
- التقسيم زمني. يتعلم النموذج من أقدم 47 مثالًا. يُثبّت الاختيار في 10 أسابيع تحقق، ثم يقاس الأداء على 11 أسبوع اختبار أحدث. حساب خصائص أسبوع اختبار قد يستخدم المبيعات الفعلية للأسابيع السابقة له، لأنها انتهت قبل إصدار توقعه. تُحسب مقاييس النموذجين على الاختبار للعرض فقط.
- `--next-promotion` يمثل عرضًا مخططًا للأسبوع التالي من خارج الملف. يحصل النموذج المثبّت على أحدث أربع قراءات لاختيار مدخلاته، ولا توجد نتيجة فعلية للأسبوع الجديد عند إجراء التنبؤ.

يقرأ `prepare.py` البيانات ويحدد خصائص الأسابيع وتقسيمها. يحسب `models.py` خط الأساس ويدرّب نموذج الانحدار. يحسب `evaluate.py` الخطأ والانحياز ويجمع `forecast.py` النتائج دون تعديل الملف المصدر.
