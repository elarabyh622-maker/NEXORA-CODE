تضم الخطة للمبتدئ من الصفر 55 درسًا تشمل 42 درسًا سابقًا في الأساسيات وPython وتحليل البيانات وpandas والإحصاء. تبقى الدروس الجديدة الـ13 للمتعلم الذي أثبت مهارتي `pd.clean` و`stat.interpret`. مهارات SQL ليست شرطًا لهذا المسار.

## مشروع توقع مبيعات الأسبوع القادم

تضم حزمة البداية `ml-sales-starter-v1.zip` سجلًا خياليًا في `data/weekly_sales.csv` وملفات تجهيز البيانات والتدريب والتقييم، إلى جانب `forecast.py` والاختبارات. تحتوي العينة 72 أسبوعًا متصلًا. تُستخدم الأسابيع الأربعة الأولى لبناء تاريخ المدخلات، فيتبقى 68 مثالًا للتوقع. يدرّب البرنامج الانحدار على أقدم 47 مثالًا، ويختار الطريقة على 10 أسابيع للتحقق، ويقيس الأداء النهائي على 11 أسبوعًا أحدث.

يقرأ `prepare.py` الملف ويفصله زمنيًا، ويحدد `models.py` خط الأساس ونموذج الانحدار، ويحسب `evaluate.py` الأخطاء. يصدر `forecast.py` تقريرًا بالعربية في `report.md`، ورسمًا في `predictions.png`، وتوقعات الاختبار في `predictions.csv`، وملخصًا في `summary.json`. [دليل المشروع المرجعي](project/reference/README.md)

بيئة التشغيل المحلية المستهدفة هي Python 3.14 ‏64-bit على Windows. بعد فك الحزمة، افتح PowerShell في المجلد الذي يحتوي `forecast.py`.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements.txt
.\.venv\Scripts\python.exe -B -m unittest -v
```

تترك الحزمة موضع `TODO` في `choose_model` داخل `forecast.py`. يُختار النموذج صاحب أقل متوسط خطأ مطلق (`MAE`) على التحقق. عند التعادل يُحتفظ بخط الأساس. بعد إكمال الموضع، أعد تشغيل الاختبارات وأنشئ التقرير في مجلد جديد.

```powershell
.\.venv\Scripts\python.exe -B -m unittest -v
.\.venv\Scripts\python.exe -B forecast.py --out-dir output --next-promotion 1
```

قيمة `--next-promotion` هي خطة العرض المعروفة قبل بدء الأسبوع التالي. أمثلة التدريب والاختبار تستخدم توقعًا متجددًا لأسبوع واحد، بحيث تكون مبيعات كل أسبوع سابق معلومة قبل موعد التوقع الجديد. يحتفظ الانحدار بمعاملاته خلال التحقق والاختبار. يرفض تجهيز البيانات التواريخ المكررة أو الفجوات، ويعامل صفر المبيعات قيمة مرصودة. عند غياب الأمثلة في مجموعة فرعية تظهر مقاييسها غائبة، وعند قلة الأمثلة يظل الفرق بين مقاييسها محدود الدلالة.

تعكس الأخطاء سجل المتجر الخيالي. يحتاج قياس الأداء في متجر فعلي إلى بيانات ممثلة له واختبار مستقل على أسابيعه. اختلاف الخطأ بين أسابيع العروض والأسابيع العادية يصف الأداء في العينة، وقد يرتبط بعوامل أخرى غير العرض.
