# أتمتة تقرير الكميات باستخدام Codex وPowerShell

يجمع المشروع كميات ستة طلبات خيالية حسب كود الصنف، ويرتّب الأصناف، ويكتب الناتج في `output/inventory-summary.csv`. التدريب يبدأ بطلب واضح لـCodex وينتهي بمراجعة التعديل وتشغيله يدويًا في الطرفية.

## ابدأ من نسخة التنزيل

1. فك ZIP في مجلد تدريب جديد وافتحه في Codex.
2. افتح PowerShell داخل نفس المجلد. الأوامر متوافقة مع Windows PowerShell 5.1 وPowerShell 7 على Windows. استخدم جلسة مسموح فيها بتشغيل السكربتات المحلية على جهازك.
3. شغّل `Test-InventoryReport.ps1` وشوف فشل مجموعة المعاينة المقصود في نسخة البداية. افتح `LEARNER-PROMPT.md` واستخدم الطلب الأول لمراجعة الخطة، ثم الطلب الثاني بعد ما توافق عليها.

```powershell
.\Test-InventoryReport.ps1
```

مهمتك تكمّل فرع `-Preview` عند موضع `TODO` في `New-InventoryReport.ps1`. اطلب من Codex إظهار التعديل ودليل الاختبار، وراجع موضع الفرع بالنسبة لأول أمر يكتب على القرص. المفروض المعاينة تعرض صفوف التقرير وترجع قبل إنشاء مجلد الإخراج أو تعديل أي ملف. الاختبارات تجرّب نسخة مؤقتة من المشروع.

## نفّذ المعاينة والكتابة بنفسك

```powershell
.\Test-InventoryReport.ps1
.\New-InventoryReport.ps1 -Preview
Test-Path -LiteralPath .\output
.\New-InventoryReport.ps1
Import-Csv -LiteralPath .\output\inventory-summary.csv
(Get-FileHash -LiteralPath .\output\inventory-summary.csv).Hash
.\New-InventoryReport.ps1
(Get-FileHash -LiteralPath .\output\inventory-summary.csv).Hash
```

في مجلد تدريب جديد، نتيجة `Test-Path` بعد المعاينة تكون `False`. التشغيل بدون `-Preview` يكتب ملف التقرير. قارن بصمة الملف قبل إعادة التشغيل وبعده. مع نفس المدخلات هتلاقي نفس البصمة، وعدد الصفوف يفضل ثلاثة.

| Sku | TotalQuantity |
| --- | --- |
| P-101 | 8 |
| P-102 | 5 |
| P-103 | 7 |

التقرير يستخدم عينة `data/orders.csv`. كل سجل في العينة يمثّل طلبًا لصنف واحد بكود طلب فريد وكمية صحيحة موجبة. لو ملف المدخل مفقود أو فيه سجل غير صالح، يوقف السكربت التنفيذ قبل كتابة التقرير. في التشغيل العادي، يكتب الملف كاملًا أولًا ثم يستبدل به التقرير السابق.

بعد اكتمال `TODO` تنجح مجموعات الاختبار الأربع. المعاينة ترجع نفس الإجماليات وتحافظ على التقرير السابق لو موجود. التحقق من الكتابة يقارن البصمات ويفحص سلامة العينة ورفض الكمية أو الرأس غير الصالح وكود الطلب المكرّر.

## سلّم دليل التنفيذ

- التعديل المراجع في `New-InventoryReport.ps1`.
- ناتج الاختبارات الأربع والصفوف الثلاثة من المعاينة.
- بصمتا التقرير المتطابقتان وشرح قصير للمكان الذي يمنع الكتابة أثناء المعاينة.
