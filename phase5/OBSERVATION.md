# بطاقة ملاحظة مشارك

انسخ البطاقة لكل مشارك إلى `phase5/.local/observations/` باسم رمزه، مثل `P01.md`. استخدم الرمز نفسه في المتابعة. دوّن الأفعال والتفسيرات بلا اسم أو بيانات اتصال أو كلمة مرور.

| بيانات الجلسة | التسجيل |
|---|---|
| رمز المشارك | |
| مبتدئ من الصفر وموافق على تدوين الملاحظات | |
| تاريخ البداية والمتابعة، والإصدار والمتصفح | |
| اختياره الحر والسيناريو المسند إليه | |
| زمن الوصول لأول حل دون تلميح أو تدخل، إن حدث | |

## المهام

الحالة لكل مهمة واحدة من **مستقل**، **بمساعدة**، **تعثر**، **لم يُنفذ**، **عطل تقني**. سجّل استخدام تلميح الواجهة حتى عند الإنجاز دون تدخل الميسّر. اذكر وقت التدخل ونصه إن حصل. لغير المنفذ اكتب السبب، واترك المهام المنتظرة للمتابعة على حالها.

| المهمة | الحالة والمدة | ما فعله أو شرحه بكلامه | التلميح أو تدخل الميسّر |
|---|---|---|---|
| S1 — وجد نقطة البداية واختار هدفًا | | | |
| S2 — شرح لماذا يسبق المتطلب الدرس التالي | | | |
| S3 — حفظ الخطة ووصل لأول درس وفهم المطلوب | | | |
| S4 — وجد التلميح واستخدمه عند الحاجة | | | |
| S5 — فهم نتيجة التصحيح وحدد خطوته التالية | | | |
| S6 — رجع لخطة المسار أو استعاد محاولته | | | |
| L1 — جرّب المعمل ثم فسّر نتيجة تقييمه | | | |

## المراجعة

- **ما كان واضحًا** —
- **ما أوقفه أو احتاج إلى مساعدة** —
- **كيف وصف خطوته التالية أو معنى النتيجة** —
- **الخطوة التي وقع فيها العائق ومعرف الدرس أو التمرين** —
- **أثر العائق على المهمة وإمكانية تكراره** —
- **الإصلاح المقترح وإعادة التحقق المطلوبة** —

عند جمع البطاقات، احسب المقام لكل مهمة من المشاركين الذين نفذوها فعليًا. أظهر عدد المستقلين وعدد من استعانوا بتلميح أو بالميسّر، وأبقِ العوائق التقنية والمهام المؤجلة ظاهرة في الملخص.
