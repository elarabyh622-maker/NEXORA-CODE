# المرحلة الخامسة — تجربة المبتدئين وتحسين الرحلة

**القبول البشري PENDING.** تستهدف التجربة من 5 إلى 10 مبتدئين يقرؤون العربية ويبدأون من الصفر. تُجرى جلسة البداية ثم متابعة المعمل بعد وصول المشارك لمتطلباته. عدد الجلسات البشرية المسجلة حتى الآن **0**.

## نسخة التجربة المحلية

[افتح صفحة اختيار المسار](http://localhost:5185/#start) من جهاز المضيف. تستخدم النسخة قاعدة PostgreSQL باسم `masar_phase5_pilot` وبيانات جلسات خاصة بها، وتشترك مع التطبيق في مختبر Python وJavaScript المعزول.

بعد إعادة تشغيل Windows، ابدأ النسخة من PowerShell.

```powershell
& 'F:\تعلم برمجه\phase5\Start-Pilot.ps1'
```

استخدم `-Initialize` عند إعداد نسخة التجربة لأول مرة. يهيئ الأمر قاعدة التجربة ويحمّل الإصدار `phase4-ar-v1`. الإصدار النشط على رابط المتعلمين الآن هو `phase7-ar-v1`؛ لإعادة تشغيل التطبيق على القاعدة الموجودة، شغّله دون `-Initialize`. ينتظر الأمر PostgreSQL حتى عشر دقائق أثناء التشغيل البارد. ابدأ جلسة كل مشارك في ملف متصفح مستقل بحساب تجريبي ورمز مثل `P01`، وأجرِ الجلسات بالتتابع على جهاز المضيف.

## رابط المتعلمين عبر الإنترنت

[افتح أو شارك رابط تجربة NEXORA CODE](https://desktop-phkhegp.tail3372f6.ts.net:10000/nexora-pilot/#start). يفتح الرابط العام عبر Tailscale Funnel على المنفذ `10000` ويصل إلى نسخة التجربة على `5185`. تحقق Edge عبر المرحّل العام من شهادة HTTPS، وتسجيل حساب متعلم، وفتح خطة Python، ونطاق كوكيز الجلسة. يستمر الرابط أثناء تشغيل الجهاز ونسخة التجربة.

لإيقاف رابط التجربة بعد انتهاء الجلسات، شغّل من PowerShell:

```powershell
tailscale funnel --https=10000 off
```

## تنفيذ الجلسة

1. اختر المشاركين ووزّع سيناريوهات الأساسيات وPython والويب وفق [دليل الميسّر](SESSION_GUIDE.md).
2. سجّل كل جلسة ومتابعتها باستخدام [بطاقة الملاحظة](OBSERVATION.md).
3. راجع كيف شرح المشاركون ترتيب المتطلبات ونتيجة المحاولة، وما احتاجوا فيه إلى تلميح أو مساعدة. اربط كل عائق حرج بإصلاح ثم أعد التحقق مع مبتدئين فعليين.

يُحسم قبول المرحلة بعد وجود أدلة جلسات من الفوج عبر المسارات الثلاثة، وتحقق فهم ترتيب الخطة والنتائج، وإغلاق العوائق الحرجة. نتائج البروفة التقنية منفصلة عن بطاقات المشاركين.

## ما نُفذ وما تحقق

- **التنقل** — عند فتح درس من خطة تخصص، يرجع زر الخطة داخل الدرس ونتيجة المختبر إلى التخصص نفسه. روابط مراجعة الدرس في التقدم تُبقي إصدار المحتوى محددًا. ظهرت هذه التغييرات في النسختين المحليتين.
- **الواجهة** — نجح بناء الإنتاج و23 اختبار واجهة. نجحت فحوص Edge الستة للضيف على المنفذين 5180 و5185، بما فيها ترتيب المتطلبات، ولغة الأمثلة، والتلميح، وتنزيل مشروع الويب، والرجوع إلى التخصص.
- **البروفة بحساب تقني** — نجح التسجيل وحفظ خطة Python وتصحيح تمرين بعد تلميح. شغّل gVisor مثال تكلفة الدفاتر وأعاد `18`، ثم سجل التقييم دليل مهارة وظهر رابط الخطة الخاص بـ Python. نجح التقييم في الإعادة بعد عطل خدمة مؤقت. استعيدت مسودة الكود في فحص مستقل بعد أن حدّ الخادم طلبات إعادة التحميل في البروفة السريعة.

لفحص المسار الجديد على رابط المتعلمين، شغّل من مجلد المشروع:

```powershell
$env:NEXORA_PHASE7_BROWSER_URL = 'https://desktop-phkhegp.tail3372f6.ts.net:10000/nexora-pilot'
node .\phase7\check-browser.cjs
```

فحص المرحلة الخامسة التالي يخص نسخة اختبار يكون الإصدار الرابع نشطًا فيها:

```powershell
$env:NEXORA_BROWSER_TEST_URL = 'http://127.0.0.1:5180'
node .\phase5\check-learner-journey.cjs
```

يستخدم الفحص Edge وPlaywright. يمكن تحديد مسارهما عبر `NEXORA_EDGE_PATH` و`NEXORA_PLAYWRIGHT_CORE`.

تولى `gpt-6-astra` دليل جلسات المبتدئين، و`gpt-6.1-terra` مراجعة الرحلة وإصلاح روابطها، و`gpt-6.1-sol` فحوص Edge. تولى المنسق إعداد القاعدة والنسخة التجريبية، وإكمال الربط بالمختبر والتقدم، والتحقق والنشر المحلي.
