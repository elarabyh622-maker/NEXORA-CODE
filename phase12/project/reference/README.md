# لوحة مبيعات متجر افتراضي

ينظف المشروع ملفي CSV بـpandas، ثم يجمع الإيراد في SQLite ويحسب ملخصًا وصفيًا. يخرج تقرير HTML عربيًا ورسم PNG وملفات يمكن تدقيقها. افتح `index.html` محليًا في مجلد الإخراج. البيانات والأكواد التعليمية خاصة بهذا السيناريو الخيالي.

## التشغيل على Windows

فك ضغط الحزمة وافتح PowerShell في المجلد الذي يحتوي على `sales_report.py`. الأوامر مجربة على Python 3.14 ‏64-bit:

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements.txt
.\.venv\Scripts\python.exe -B -m unittest -v
.\.venv\Scripts\python.exe -B sales_report.py --out-dir output
```

استخدم اسم مجلد جديد لكل تشغيل. تبقى الملفات الأصلية في `data/` كما هي. لا يحتاج التقرير إلى خادم. تظهر أسماء المحاور داخل الرسم بالإنجليزية، والشرح والجدول بالعربية.

## مهمة المتعلّم

تحتوي الحزمة المنزلة على `TODO` واحد في `queries.sql`. ابدأ بتشغيل الاختبارات. يفشل اختبار المقارنة مع الشهر السابق قبل إكماله. أكمل قيمة `previous_revenue_piastres` باستخدام `LAG` بترتيب `month`. شغّل الاختبارات مجددًا، ثم أنشئ التقرير وافحص `monthly.csv` و`index.html` معًا.

- سطر المبيعات المقبول يمثل عملية واحدة. احسب القروش بأعداد صحيحة حتى اكتمال التجميع. كل 100 قرش تساوي جنيهًا.
- من 11 صفًا يقبل المشروع 5 ويحذف نسخة مكررة ويرفض 5. راجع مجموع الأعداد في `summary.json`.
- الإيراد المقبول 1,060 جنيهًا. قيّم الفرق بين إجمالي الشهر ومتوسط مبلغ العملية فيه.
- مارس غائب. مقارنة أبريل تستخدم فبراير، أقرب شهر سابق موجود، بفارق 40 جنيهًا. أول شهر بلا قيمة سابقة، وقد تكون قيمة الشهر السابق صفرًا في مجموعة أخرى.
- اكتب ثلاثة أسطر تشرح فيها ماذا تثبت الأرقام وماذا تحتاج لمعرفة سبب التغير. اختبارات الحساب لا تراجع تفسيرك.

## الملفات

`clean.py` يتحقق من السجلات ويربط رموز المنتجات. `queries.sql` يحدد جدولَيْ عرض للتقارير. `metrics.py` يلخص القيم ويرسم الإيراد. `sales_report.py` يربط المراحل، ويتحقق من تطابق أعداد الصفوف والإيراد، ويكتب النتائج. `test_report.py` يغطي التنظيف والمفاتيح والتجميع وتصدير التقرير. لا يحتوي ZIP على بيئة Python أو المكتبات أو مخرجات التشغيل.
