# هوية NEXORA CODE

| العنصر | الصيغة المعتمدة |
|---|---|
| العلامة الأم | NEXORA |
| اسم المنتج | NEXORA CODE |
| الوصف العربي | تعلّم البرمجة بالعربية |
| العبارة التعريفية في الحزمة | Learn to Think. Code to Create. |
| المنتجات الشقيقة | NEXORA-HR وNEXORA-ERP |
| نموذج المنتج | منصة تعليمية مدفوعة |

يُكتب الاسم بأحرف لاتينية كبيرة مع مسافة واحدة بين الكلمتين. يظهر الاسم باتجاه يسار إلى يمين داخل الواجهة العربية. تُبنى النصوص التعليمية على لغة واضحة تناسب مستوى المتعلم وتوضح سبب كل خطوة.

## ألوان الحزمة

| اللون | القيمة | الاستخدام |
|---|---|---|
| Forest Green | `#0B3D2E` | التنقّل والعناوين والأسطح الداكنة |
| Emerald Green | `#16A34A` | إبراز الإجراءات وحالات النجاح، مع اختيار لون النص بحسب التباين |
| Lime Green | `#A3E635` | الإبراز ومؤشر التركيز على الخلفيات الداكنة |
| Pale Mint | `#E8F5E9` | خلفيات البطاقات والأسطح الثانوية |
| Off White | `#F8FBF6` | خلفية الصفحة |

تستخدم الواجهة Cairo للنص العربي وInter للنص اللاتيني. نسخ الويب وتراخيص OFL مضمّنة في `phase2/apps/web/public/brand/fonts`. تُستخدم الدرجة `#087332` للأزرار الأساسية كي يظل النص الفاتح واضحًا. [Cairo](https://github.com/google/fonts/tree/main/ofl/cairo) و[Inter](https://github.com/google/fonts/tree/main/ofl/inter).

## استخدام الشعار

تتضمن الحزمة نسخة أفقية ونسخًا تناسب الخلفيات الفاتحة والداكنة، بالإضافة إلى أيقونات متعددة الأحجام. تُستخدم ملفات PNG الموردة للعرض داخل التطبيق مع الحفاظ على نسبها. توصي الحزمة بإعادة رسم الشعار كمسارات متجهة بصيغة SVG استعدادًا لأعمال الطباعة أو إعداد ملفات تسجيل العلامة.

مرجع الألوان والخطوط والأصول هو `NEXORA_CODE_Brand_Kit/04_Guidelines/NEXORA_CODE_Brand_Guidelines.md` داخل الحزمة المرفقة.

## النسخة الحالية

تستخدم الواجهة «عينة» للدروس الموجودة في نسخة التطوير. يُحدَّد السعر وطريقة التحصيل وسياسة المعاينة العامة قبل الإطلاق التجاري. تستخدم سجلات النموذج الأول اسم «مسار»، وتحتفظ السكربتات والمكونات بمعرّفات `Masar` لضمان توافق التشغيل والبيانات.
