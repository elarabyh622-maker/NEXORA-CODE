# NEXORA CODE | المرحلة الثالثة

تضيف المرحلة مختبرًا داخل درسين من عينة الأساسيات. تمرين Python يقرأ اسمًا ويطبعه ضمن رسالة ترحيب. تمرين JavaScript يختبر ترتيب العمليات لحساب السعر. تُربط التمارين بالإصدار المنشور `phase1-ar-v1` ومهاراته.

يحفظ المحرر المسودة تلقائيًا في حساب المتعلم ويعرض النسختين عند التعارض. «جرّب الكود» يعرض مخرجات إدخال يختاره المتعلم. «تحقّق من الحل» يجري حالات اختبار محددة ويعرض عدد الحالات المجتازة. يسجل اجتياز الحالات كلها دليلًا واحدًا لكل تمرين في الحساب. يُستخدم هذا الدليل عند معاينة خطة جديدة لنفس إصدار المحتوى. تظل مراجعات الخطط السابقة قابلة للعرض.

يعمل المختبر بطابور PostgreSQL. لكل محاولة لقطة ثابتة من الشيفرة وإصدار التمرين ومفتاح يحول دون تسجيل الطلب مرتين. تحفظ حالة انتهاء المهلة أو تعطل المشغّل من دون إصدار حكم على الحل. تفاصيل تشغيل وسيط Linux واختبار العزل في [دليل المشغّل](runner/README.md).

## تشغيل النسخة المحلية

عند ترقية نسخة سابقة، أوقف خادم التطبيق الجاري أولًا لأن Windows يقفل ملف التجميع أثناء استخدامه. ابنِ التطبيق وشغّل ترحيل المخطط ثم ابدأ الخادم. يضيف الترحيل جداول المختبر مع الاحتفاظ بالحسابات والبيانات.

```powershell
& 'F:\تعلم برمجه\phase2\scripts\Build-Masar.ps1'
& 'F:\تعلم برمجه\phase2\scripts\Update-MasarSchema.ps1' -Engine Portable
& 'F:\تعلم برمجه\phase2\Start-Masar.ps1' -Engine Portable
```

افتح [NEXORA CODE محليًا](http://127.0.0.1:5180/#lesson/what-is-a-program). تظهر التمارين وحفظ المسودات في الوضع المحلي. أمر التشغيل اليومي بعد إعداد البيئة هو `host/Start-NexoraLab.ps1`؛ ولتشغيل اختبارات المشغّل الفعلي استخدم الأمر نفسه مع `-Test`. جرى إعداد مضيف Ubuntu 24.04 على QEMU/WHPX، مع Docker 29.1.3 على cgroup v2 ومشغّل gVisor `release-20261109.0`. تم التحقق من صور Ubuntu الرسمية الموقعة، وصور Python وNode مثبتة بالـ digest. فحوص Python وNode الفعلية، بما فيها النص العربي/Unicode والمخرجات والإخفاق، انتهاء مهلة المتعلم عند 4 ثوانٍ (باستخدام مسبار نوم 60 ثانية)، والتنظيف بمهلة مستقلة والتأكد من عدم بقاء حاويات مملوكة، PASSED. شبكة الضيف مقيدة ولا تصل مباشرة إلى API على Windows.

## ربط المشغّل

بعد اجتياز فحوص المشغّل على مضيف Linux المخصص، اضبط متغيرات عملية API التالية من مخزن الإعدادات الخاص بها. يقبل API عنوان HTTPS الأساسي للمشغّل من دون مسار. يسمح بـ HTTP على loopback لوكيل محلي أو اختبار التكامل. يستخدم API رمز Bearer نفسه المضبوط في المشغّل. احتفظ بالرمز خارج ملفات المصدر.

| المتغير | القيمة |
|---|---|
| `MASAR_CODE_LAB_ENABLED` | `true` |
| `MASAR_CODE_LAB_RUNNER_URL` | عنوان HTTPS الأساسي |
| `MASAR_CODE_LAB_RUNNER_TOKEN` | رمز Bearer الخاص |

## التحقق

بعد البناء، يتحقق هذا الأمر من تكامل API مع PostgreSQL عبر قاعدة الاختبار المخصصة وخادم مؤقت على المنفذ 5182. يحاكي الطرف الذي يرد على طلب التنفيذ بنتائج ثابتة، ولا يفسر شيفرة المتعلم. يغطي صلاحيات المسودات واستعادتها بعد إعادة التشغيل، والتصحيح ومنع احتساب الدليل مرتين وتعديل معاينة الخطة.

```powershell
& 'F:\تعلم برمجه\phase3\Test-CodeLab.ps1'
python -B -m unittest discover -s 'F:\تعلم برمجه\phase3\runner' -v
```

اجتازت اختبارات المشغّل المحلية **17/17**. اجتازت أيضًا مجموعة HTTP على PostgreSQL الحقيقي عبر SSH، وشملت تجارب Python وJavaScript وتقييمهما، والمهلة والمخرجات والأخطاء، والخصوصية وCSRF، ومنع تكرار الدليل والخطة، واستمرار البيانات بعد إعادة تشغيل API. واجتاز فحص Playwright على Edge التسجيل وتشغيل Python على قاعدة الاختبار. تم تفعيل المختبر محليًا على `127.0.0.1:5180`، وظهر كتالوج التمارين الحية لـ `python-greeting` و`javascript-price`؛ ولم تبقَ حاويات مملوكة للمشغّل بعد القبول. بذلك اكتملت المرحلة الثالثة محليًا ضمن نطاق تمارين الكونسول Python/JavaScript. معاينة HTML/CSS وتشغيل اختبارات واجهات الويب في متصفح معزول ضمن العمل اللاحق. قبول Phase 3 لا يغلق تجربة المبتدئ البشرية المطلوبة للمرحلة الأولى ولا يمثل إطلاقًا عامًا.
