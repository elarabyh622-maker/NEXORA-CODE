# تقرير البحث والعد

مشروع مسار «الخوارزميات وهياكل البيانات» بنسختين مستقلتين. تحتاج Python 3.10 أو أحدث لتشغيل `search.py`، أو Node.js 22 أو أحدث لتشغيل `search.cjs`. ابدأ باللغة التي تتعلمها. تستخدم النسختان المكتبة القياسية المرفقة ببيئة التشغيل.

## التشغيل في PowerShell

افتح PowerShell في المجلد الذي يحتوي على ملفات المشروع. نفّذ أمر اللغة التي اخترتها.

```powershell
'{"values":[12,2,12,25],"target":12}' | python search.py
'{"values":[12,2,12,25],"target":12}' | node search.cjs
```

الناتج المتوقع بعد إكمال البحث الثنائي هو السطر التالي.

```json
{"linearIndex":0,"binaryIndex":1,"occurrences":2}
```

اقرأ من الإدخال القياسي كائن JSON واحدًا بحقلي `values` و`target`. يحتوي `values` على ما يصل إلى 50 عددًا صحيحًا بين ‎-1000 و1000 بترتيب اختياري. يخضع `target` للمدى نفسه. يدعم المشروع التكرار والقائمة الفارغة ويقبل تمثيل العدد الصحيح مثل `12.0`. عند مخالفة العقد تظهر `invalid input` على قناة الأخطاء ويخرج البرنامج برمز `2`.

- `linearIndex` فهرس أول تطابق في القائمة الأصلية.
- `binaryIndex` فهرس أول تطابق في نسخة مرتّبة عدديًا تصاعديًا. يبدأ الفهرسان من الصفر، وقيمتهما `-1` عند غياب الهدف.
- `occurrences` عدد مرات ظهور الهدف، وقيمته `0` عند غيابه.

## المطلوب

أكمل موضع `TODO` في `first_binary_index` داخل `search.py` أو `firstBinaryIndex` داخل `search.cjs`. تتلقى الدالة النسخة المرتّبة والهدف جاهزين. استخدم نطاقًا نصف مفتوح يبدأ عند الصفر وينتهي عند طول القائمة. ضيّق النطاق باتجاه أول موضع يمكن أن يكون فيه الهدف أو قيمة أكبر. بعد انتهاء الحلقة، افحص صلاحية الفهرس وتطابق القيمة. يقبل البرنامج التكرار، لذا استمر في البحث عن الموضع الأول عند المساواة.

## الاختبارات

```powershell
python -B -m unittest -v test_search.py
node --test test_search.cjs
```

قبل إكمال عملك ينجح أربعة اختبارات من خمسة في كل لغة. اختبار `test_duplicate_uses_first_index_in_sorted_copy` في Python، أو `duplicate uses first index in sorted copy` في JavaScript، يفشل لأن `binaryIndex` يخرج `-1` حتى عند وجود الهدف. بعد الإكمال تمر الاختبارات الخمسة للنسخة التي عدّلتها. تحقّق أيضًا من مثال التشغيل أعلاه، ودوّن الفرق بين الفهرسين وتكلفة ترتيب القائمة قبل البحث عليها.
