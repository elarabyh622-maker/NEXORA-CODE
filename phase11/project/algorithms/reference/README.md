# تقرير البحث والعد

مشروع مسار «الخوارزميات وهياكل البيانات» بنسختين مستقلتين. تحتاج Python 3.10 أو أحدث لتشغيل `search.py`، أو Node.js 22 أو أحدث لتشغيل `search.cjs`. يمكنك إنجاز المشروع باللغة التي تتعلمها وتشغيل النسخة الثانية للمقارنة. تستخدم النسختان المكتبة القياسية المرفقة ببيئة التشغيل.

## التشغيل في PowerShell

افتح PowerShell في المجلد الذي يحتوي على ملفات المشروع. نفّذ أمر اللغة التي اخترتها.

```powershell
'{"values":[12,2,12,25],"target":12}' | python search.py
'{"values":[12,2,12,25],"target":12}' | node search.cjs
```

يعطي كلا الأمرين السطر التالي.

```json
{"linearIndex":0,"binaryIndex":1,"occurrences":2}
```

اقرأ من الإدخال القياسي كائن JSON واحدًا بحقلي `values` و`target`. يحتوي `values` على ما يصل إلى 50 عددًا صحيحًا بين ‎-1000 و1000 بالترتيب الذي تختاره. يخضع `target` للمدى نفسه. يدعم المشروع التكرار والقائمة الفارغة ويقبل تمثيل العدد الصحيح مثل `12.0`. عند مخالفة العقد تظهر `invalid input` على قناة الأخطاء ويخرج البرنامج برمز `2`.

- `linearIndex` فهرس أول تطابق في القائمة الأصلية.
- `binaryIndex` فهرس أول تطابق في نسخة مرتّبة عدديًا تصاعديًا. يبدأ الفهرسان من الصفر، وقيمتهما `-1` عند غياب الهدف.
- `occurrences` عدد مرات ظهور الهدف، وقيمته `0` عند غيابه.

## الاختبارات

```powershell
python -B -m unittest -v test_search.py
node --test test_search.cjs
```

تمر الاختبارات الخمسة لكل لغة في هذه النسخة المرجعية. تشغّل الاختبارات الأداة نفسها بالمدخلات عبر `stdin` وتفحص المخرجات. تشمل البحث في نسخة مرتّبة مع التكرار، والهدف الغائب، والقائمة الفارغة، والتحقق من شكل البيانات، وJSON غير صالح. جرّب تعقب قيم الحدين في البحث الثنائي يدويًا لمثال التشغيل.

## فهم الملفات

تقسّم النسخة المرجعية العمل بين قراءة الإدخال، وحساب التقرير، وطباعته. في Python تقرأ `json.load(sys.stdin)` المستند من الإدخال القياسي، وتعيد `sorted(values)` قائمة جديدة. في JavaScript تقرأ `fs.readFileSync(0, "utf8")` الإدخال القياسي كنص، ويحوّله `JSON.parse` إلى قيمة. تنسخ `slice()` المصفوفة قبل أن يغيّرها `sort`، وتعيد دالة المقارنة `(first, second) => first - second` قيمة سالبة أو صفرًا أو قيمة موجبة لتحديد ترتيبهما. الامتداد `.cjs` يتيح استيراد مكتبات Node عبر `require`.

تقع تكلفة ترتيب النسخة ضمن تكلفة إعداد التقرير. يقل عدد خطوات البحث الثنائي على نسخة جاهزة ومرتبة إلى O(log n)، بينما يفحص البحث الخطي حتى n عنصرًا في القائمة الأصلية. يستخدم التقرير جدول تكرارات لشرح آلية العد. لعد هدف واحد فقط تكفي زيادة عداد أثناء المرور على العناصر.
