# كتالوج المنتجات

تخزّن خدمة FastAPI المنتجات في ملف SQLite على جهازك. يعرض المتصفح المنتجات ويتيح للمسؤول تعديلها. استخدم Python من 3.11 إلى 3.14 مع SQLite 3.37 أو أحدث. تبدأ قاعدة البيانات فارغة.

## مهام نسخة البداية

يعمل عرض الكتالوج والدخول والإضافة والحذف منذ البداية. ابحث عن علامات `TODO` وأكمل السلوك التالي بالترتيب.

1. في `catalogue/store.py` اجعل `list_products` يرشّح بالاسم والتصنيف. شغّل اختبار `test_filter_binds_user_text` قبل التعديل وبعده.
2. في الملف نفسه أكمل `update_product` ثم شغّل `test_crud_and_restart`. يُرجع المسار 404 حتى تنفّذ تحديث المنتج. يُتوقع أن يفشل هذان الاختباران في أول تشغيل وأن ينجحا بعد إكمال المهمتين.
3. في `catalogue/static/app.js` اربط مدخلات نموذج البحث بطلب GET. أضف منتجين بتصنيفين مختلفين، وابحث بجزء من الاسم ثم بالتصنيف. افحص رابط الطلب في Network وقارن النتائج في المتصفح بالاستجابة.

لتشغيل حالة منفردة بعد تثبيت المتطلبات استعمل مثلًا `.\.venv\Scripts\python.exe -m pytest -q -k test_filter_binds_user_text`. سجّل نتيجتك قبل كل تعديل وبعده. عند تسليم API أرفق نتائج الاختبارات. وعند تسليم التطبيق الكامل أرفق أيضًا مشاهدات البحث والإدارة بحسابَي المسؤول والقارئ.

## التشغيل على Windows

افتح PowerShell داخل المجلد الذي يحتوي على `requirements.txt` ونفّذ الأوامر بالترتيب. اختر اسمًا لحسابك، واكتب كلمة مرور جديدة من 12 إلى 128 حرفًا عند ظهور المطالبة المخفية.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m catalogue create-user manager --role admin
.\.venv\Scripts\python.exe -m catalogue create-user observer --role reader
.\.venv\Scripts\python.exe -m catalogue serve
```

على macOS أو Linux أنشئ البيئة باستخدام `python3 -m venv .venv` ثم استبدل `.\.venv\Scripts\python.exe` في الأوامر الأخرى بـ `.venv/bin/python`. تعمل أمثلة `python -m ...` في الدروس بعد تفعيل البيئة.

افتح الكتالوج على [127.0.0.1:8000](http://127.0.0.1:8000/). تستخدم صفحة [توثيق API](http://127.0.0.1:8000/docs) مكتبات العرض من CDN. يمكن فتح [عقد OpenAPI](http://127.0.0.1:8000/openapi.json) محليًا. أوقف الخادم بـ Ctrl+C.

## تجربة كاملة

1. افتح الكتالوج وسجّل الدخول باسم المسؤول. أضف «دفتر» ضمن «قرطاسية» بسعر 1250 قرشًا ومخزون 3. يظهر السعر على الشاشة 12.50 جنيهًا.
2. ابحث عن «دف» واختر التصنيف بكتابة «قرطاسية». جرّب اسمًا آخر ثم امسح حقلي البحث لعرض كل المنتجات.
3. عدّل المخزون إلى صفر، ثم أعد تشغيل الخادم من المجلد نفسه. يبقى المنتج في `data/catalogue.sqlite3`. يمكنك تحديد ملف آخر بتعيين متغير البيئة `CATALOGUE_DB` قبل إنشاء الحساب وتشغيل الخادم.
4. سجّل الدخول بحساب القارئ وافتح المنتج. استخدم صفحة التوثيق لتجربة تعديل يتطلب صلاحية المسؤول. أعد الدخول بالمسؤول لحذف المنتج وتأكد من اختفائه بعد التحديث.

## عقد الطلبات

| الطلب | النتيجة |
| --- | --- |
| `GET /api/products?q=دف&category=قرطاسية` | مصفوفة منتجات مرتبة بالمعرّف. يبحث q في الاسم ويطابق category التصنيف كاملًا. كلاهما اختياري. |
| `GET /api/products/{id}` | المنتج المطلوب، أو 404 عند غيابه. |
| `POST /api/login` | أرسل username وpassword. استلم access_token وtoken_type وrole. |
| `GET /api/me` | اسم المستخدم ودوره من قاعدة البيانات للجلسة الحالية. |
| `POST /api/logout` | إبطال الجلسة الحالية وإرجاع 204. |
| `POST /api/products` | إنشاء منتج للمسؤول وإرجاع 201 مع المعرّف. |
| `PUT /api/products/{id}` | استبدال حقول المنتج الأربعة وإرجاع النسخة المحدّثة. |
| `DELETE /api/products/{id}` | حذف منتج للمسؤول وإرجاع 204 بجسم فارغ. |

جسم إنشاء المنتج وتعديله مثل `{"name":"دفتر","category":"قرطاسية","price_minor":1250,"stock":3}`. تضيف الاستجابة حقل `id`. تُرسل الجلسة في ترويسة `Authorization: Bearer <access_token>`. في صفحة التوثيق انسخ رمز جلسة التدريب إلى حقل **Authorize**. يعني 401 أن الطلب يحتاج جلسة صالحة، و403 أن الحساب يفتقر إلى الدور المطلوب، و422 أن البيانات لا تطابق العقد.

يحتفظ المتصفح بالرمز في ذاكرة الصفحة ويطلب الدخول مرة أخرى بعد تحديثها. تنتهي الجلسة في الخادم بعد ساعة. تقبل عملية الخادم المحلي ثماني محاولات دخول في الدقيقة. يمكن للزائر والقارئ تصفح المخزون.

## الاختبارات

افتح نافذة PowerShell ثانية من المجلد نفسه. تستخدم الاختبارات ملفًا مؤقتًا لكل حالة وتنشئ كلمات مرور عشوائية لحسابات الاختبار.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

ابدأ القراءة من `catalogue/app.py` لرؤية المسارات والتحقق من القيم، ثم `catalogue/store.py` للجداول والمعاملات و`catalogue/auth.py` لكلمات المرور والجلسات. تعالج ملفات `catalogue/static/` النماذج والبحث وعرض الاستجابات. توجد الشروط الخاصة بحزم الطرف الثالث في [سجل التراخيص](LICENSES.md).
