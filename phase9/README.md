## مشروع الكتالوج

تنزل نسخة البداية من بطاقة المشروع في الدرس `backend-07` أو `fullstack-02`. تُحزم الملفات من [مصادر البداية](project/starter/README.md) في `phase2/apps/web/public/projects/backend-starter-v1.zip`. يتضمن التنزيل تعليمات إنشاء بيئة محلية وحسابَي تدريب بمطالبة كلمة مرور مخفية، واعتمادات مثبتة الإصدارات وسجل تراخيص واختبارات. توضّح التعليمات اختبارَي التصفية والتعديل اللذين يفشلان أولًا حتى يكمل المتعلم المهام، ومهمة ربط البحث في الواجهة.

يعرض [المرجع المكتمل](project/reference/README.md) التنفيذ لمراجعة التأليف. تفصل الحزمة التعليمية ملفات البداية عن مصدر المرجع. يستخدم المشروع FastAPI وPydantic وSQLite، ويستضيف واجهته على الأصل نفسه. تستعمل الصلاحيات الدور الحالي من القاعدة، وتبقى رموز الجلسات في ذاكرة الواجهة. تُحفظ مشتقات كلمات المرور باستخدام scrypt وبصمات رموز الجلسات مع وقت انتهائها. يتوفر [سجل التراخيص](project/LICENSES.md) مع إصدارات الاعتمادات.

تعمل خدمة التدريب وطلبات FastAPI على جهاز المتعلم من البيئة الموضحة في README. تعرض المنصة الشرح وتمارين التتبع المصححة، ويستخدم مختبرا Python الجديدان المكتبة القياسية.

تشغيل مختبر الأكواد داخل المنصة التجارية متوقف بخيار `-WithoutLab` من إعداد التشغيل الحالي. يبقى مشروع الكتالوج القابل للتنزيل قابلًا للتشغيل محليًا وفق تعليماته.

## البناء والتحقق

شغّل الأوامر من جذر المشروع بعد إعداد بيئة مشروع الكتالوج.

```powershell
python -B phase9/build_curriculum.py
python -B phase9/build_curriculum.py --check
dotnet build phase2/src/Masar.Api/Masar.Api.csproj --no-restore --output phase9/.local/api
dotnet phase9/.local/api/Masar.Api.dll --verify-curriculum ((Resolve-Path 'phase9/dist/curriculum.json').Path)
```

يقبل فاحص الأمثلة `--project-python` لمسار مفسر يحتوي الاعتمادات المثبتة في ملف متطلبات المشروع. في بيئة التطوير الحالية يستخدم `phase9/project/.local/venv/Scripts/python.exe`. ينفذ الفاحص 23 حالة مستقلة لقيود SQLite ومعاملاتها، والأمثلة المعروضة التسعة نفسها على اتصال واحد، ثم يعيد فتح الملف للتحقق من الاستمرار. يتحقق كذلك من 22 حالة Python وحالتَي JavaScript ومن تطابق ملفات ZIP مع مصادر البداية.

بصمة الحزمة هي `bf66b58d76aaa54bd0d760eecde443cb7c98081b474c0e04ffe92ee9973d525a`.

يشغّل [فحص إصدار المنهج](check-release.py) PostgreSQL مؤقتًا على منفذ متاح، ويختبر التفعيل المتكرر وبقاء خطة المرحلة الثامنة ومسارات المتعلم الجديد والمتعلم صاحب المهارات السابقة. يختبر الأسعار وصلاحيات المحتوى وتنزيل ZIP وإلغاءها في الجلسة نفسها. يحتاج `--postgres-bin` إلى مسار ASCII لأدوات PostgreSQL Windows.

```powershell
. .\phase2\scripts\Local-Environment.ps1
$pgBin = Join-Path (Get-MasarPortableNativeRoot) 'binaries/pgsql/bin'
python -B phase9/check-release.py ((Resolve-Path 'phase9/.local/api/Masar.Api.dll').Path) --postgres-bin $pgBin
```

اجتاز المرجع اختبارات API التسعة على قاعدة SQLite فعلية مؤقتة. اجتاز Edge رحلة القارئ والمدير والبحث والتصفية والتعديل والحذف واستمرار البيانات، مع فحص خطأ طلب قديم ورد أحدث. شملت المراجعة المستقلة تطابق قيود Pydantic وSQLite وغياب بيانات التشغيل والأسرار عن ملفات البداية.
