## تشغيل المشروع

نزّل `java-library-starter-v1.zip` من درس المشروع بعد تفعيل الوصول. جهّز JDK 21 وافتح PowerShell في مجلد المشروع بعد فكّه. أكمل `Lending.borrow` ثم شغّل اختبارات Java للتحقق من الإعارة وحفظ البيانات في `data/books.tsv`. [دليل المشروع والأوامر](project/reference/README.md) · [تجهيز Java](https://dev.java/learn/getting-started/)

**السعر المقترح للمسار 699 جنيه مصري**، بنفس سعر مساري C++ وC# في الكتالوج وقت إضافة المسار. يُضبط سعر البيع من لوحة الإدارة.

## بناء الحزمة والتحقق منها

شغّل الأوامر التالية من جذر المستودع بعد تجهيز Python وJDK 21. مرّر `--jdk` مع مجلد تثبيت JDK إذا لم يكن `javac` متاحًا عبر `PATH`.

```powershell
python -B phase17/build_curriculum.py
python -B phase17/build_curriculum.py --check
```

يفحص أمر `--check` تطابق الحزمة مع مصادرها، ويشغّل أمثلة الدروس في مجلدات مؤقتة، ويتحقق من ملفات أرشيف البداية. يفحص [اختبار الإصدار](check-release.py) ترقية المنهج على PostgreSQL مؤقت، وخطة المتعلم السابقة، والتصحيح، وحماية الدرس والتنزيل.

يضم `phase17-ar-v1` إجمالًا 185 درسًا و529 تمرينًا و24 هدفًا و48 مختبر كونسول. أمثلة Java ومشروعها يعملان محليًا باستخدام JDK 21.

بصمة SHA-256 لحزمة المنهج هي `ea7ab0d56b10621d45783330df6bdb465cd54cd8ae6f96282cc553218c074355`. اجتازت أمثلة الدروس الـ12 ست عشرة حالة تشغيل على Windows باستخدام Temurin JDK 21. اجتاز الحل المرجعي 144 فحصًا، واجتاز قالب البداية 105 فحوص للأجزاء الجاهزة. بعد إكمال دالة الإعارة، اجتاز المشروع المستخرج من القالب 144 فحصًا.
