# منهج NEXORA CODE — المرحلة الرابعة

الإصدار `phase4-ar-v1` يضيف 36 درسًا بالعربية، و96 تمرينًا مصححًا، و15 مختبرًا برمجيًا، و3 مشروعات تطبيقية، و50 مصطلحًا. يمكن للمتعلم البدء بالأساسيات، أو اختيار الأتمتة بـ Python، أو اختيار تطوير الويب بـ HTML وCSS وJavaScript. تبدأ خطتا الأتمتة والويب بأساسيات البرمجة ثم تنتقل كل خطة إلى دروس تخصصها.

| المسار | الدروس المخصصة | المشروع |
|---|---:|---|
| أساسيات البرمجة | 12 | تصميم خوارزمية والتحقق من نتائجها |
| الأتمتة بـ Python | 12 | تصنيف ملفات افتراضية وعرض ملخص دون تغيير الملفات |
| تطوير الويب | 12 | بناء صفحة تفاعلية بالعربية من قالب HTML وCSS وJavaScript |

يعمل مختبر التطبيق مع Python وJavaScript للكونسول. يُفتح مشروع الويب في المتصفح بعد تنزيل القالب من درس المشروع.

## التشغيل المحلي

من PowerShell على المضيف:

```powershell
& 'F:\تعلم برمجه\phase3\host\Start-NexoraLab.ps1'
```

افتح [صفحة اختيار المسار](http://127.0.0.1:5180/#start). راجع [دليل المضيف](../phase3/host/README.md) إذا لم يكن المضيف أو النفق قيد التشغيل.

## بناء المنهج والتحقق منه

ملفات المصدر في [content](content/). يبني `python -B phase4/build_curriculum.py` الحزمة `phase4/dist/curriculum.json`، وقالب مشروع الويب في ملفات الواجهة، وقائمة التحقق الخاصة في `phase4/.local/`. لا تدخل حلول المختبر المرجعية ضمن بيانات الدروس المنشورة.

بعد تثبيت تبعيات التطبيق كما في [دليل المرحلة الثانية](../phase2/README.md)، يبني `phase4/Build-Curriculum.ps1` نسخة مرحلية مستقلة ويتحقق من الدروس والتمارين والخطط. يشغّل `phase4/Test-Curriculum.ps1` تحقق التنفيذ الفعلي عبر المختبر ويختبر الإصدار المنشور باستخدام قاعدة `masar_phase2_tests`. يتحقق `node phase4/validate-web.cjs` من صفحة المشروع وأمثلة الويب باستخدام Edge وPlaywright.

يشغّل `phase4/Install-Curriculum.ps1 -ReviewedSha256 <SHA-256>` التثبيت المحلي للحزمة المطابقة للبصمة التي طبعتها اختبارات القبول. يبقى الإصدار الأصلي `phase1-ar-v1` متاحًا للروابط القديمة والتقدم المسجل عليه.

## نتائج القبول

- **محرك المنهج والواجهة** — نجحت 110 اختبارات .NET و23 اختبار واجهة، ونجح بناء الإنتاج.
- **التنفيذ** — نجحت 86 حالة مرجعية في Python وJavaScript على gVisor. أعيدت حالة واحدة انتهت مهلتها، ونجحت في الإعادة.
- **PostgreSQL** — نجح التحقق من خطط المسارات ذات 12 و24 و24 درسًا، وتصحيح الإجابات، وأدلة المختبر للإصدارين، واستمرار التقدم بعد إعادة تشغيل خادم الاختبار.
- **Edge على التطبيق المحلي** — ظهرت المسارات الثلاثة، وعمل تنزيل قالب المشروع، وفتحت خطة الويب مثال JavaScript في درس الأساسيات، وعمل رابط العينة القديمة.

تجربة المبتدئين الفعلية ضمن المرحلة الخامسة. الإطلاق التجاري والتسعير والتحصيل ضمن مراحل الإطلاق.
