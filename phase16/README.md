## التطبيق على Windows

شغّل الأمثلة والمشروع على جهازك باستخدام مترجم يدعم C++20. يوضح الدرس الأول طريقة تجهيز GCC في طرفية MSYS2 UCRT64، ويشرح دليل المشروع طريقة البناء من طرفية الأدوات المناسبة. [بيئات MSYS2](https://www.msys2.org/docs/environments/) · [حزمة GCC لـUCRT64](https://packages.msys2.org/package/mingw-w64-ucrt-x86_64-gcc)

نزّل `cpp-expenses-starter-v1.zip` من الدرس بعد تفعيل الوصول. يقرأ البرنامج ملفًا نصيًا فيه الفئة والمبلغ بالقروش، ويضيف السجلات ويعرضها بين تشغيلات منفصلة. أكمل `summarize` لحساب الإجماليات، ثم تحقّق باستخدام اختبارات PowerShell والبيانات الخيالية. [دليل البناء والتجربة](project/reference/README.md)

## بناء الحزمة وفحصها

نفّذ من جذر المستودع بعد تجهيز Python والمترجم.

```powershell
python -B phase16/build_curriculum.py
python -B phase16/build_curriculum.py --check --compiler g++
```

يترجم الفحص أمثلة الدروس في مجلدات مؤقتة ويقارن ناتجها بالحالات المعتمدة، ثم يطابق أرشيف البداية مع مصادره. يتحقق [اختبار الإصدار](check-release.py) في PostgreSQL مؤقت من الترقية، ومن خطط التعلم، والتصحيح، وحماية الدرس والتنزيل.

بصمة `phase16-ar-v1` هي `2d8077bfcc2e9357f855e37858429b91f54be23591cf902fe3a239269417c621`. نجح تنفيذ الأمثلة الـ12 على Windows باستخدام GCC 16.2.0. نجحت اختبارات المرجع العشرة، ونجحت فحوص نسخة البداية الثمانية في النطاق المكتمل. اجتازت نسختا المشروع فحوص المتعلم المناسبة على PowerShell 5.1 و7. تُستكمل فحوص الإجماليات الثلاثة بعد تنفيذ دالة `summarize` في نسخة المتعلم.
