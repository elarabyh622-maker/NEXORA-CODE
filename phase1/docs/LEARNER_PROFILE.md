# ملف المتعلم ونتيجة العينة

## المتعلم المقصود
شخص يقرأ العربية ويستخدم جهازًا لفتح صفحة والتنقل والنقر وكتابة إجابة قصيرة، ولم يسبق له تعلّم البرمجة أو قراءة الكود. لا يُفترض أنه يعرف الإنجليزية أو معنى «متغير» أو أسماء اللغات. نستخدم عربية مبسطة ونشرح المصطلح قبل الاعتماد عليه.

العمر غير محدد. نفترض مبدئيًا مشاركًا بالغًا لتسهيل تجربة أولية طوعية، لا باعتباره حدًا للمنتج؛ اختيار الأعمار الأخرى وإجراءات إشراك القُصّر قرار لاحق. نفترض جهاز كمبيوتر بمتصفح حديث ولوحة مفاتيح، ونوثّق جهاز التجربة الفعلي بصورة عامة؛ صلاحية الهاتف والإتاحة تحتاجان فحصًا مستقلًا. هذه افتراضات قابلة للتحقق وليست وصفًا لمشارك جرت مقابلته.

## ما نريد أن يحققه
بعد العينة يستطيع المتعلم، بلغته الخاصة، وصف البرنامج باعتباره خطوات تتعامل مع مدخلات ومخرجات، وتتبع ترتيب خطوات بسيط، وفهم المتغير كاسم لقيمة في المثال، ومحاولة تطبيق جديد على كل درس. يرى لماذا يبدأ بالأساسيات قبل الخطوة التالية، ويجد تقدمه المحلي عند العودة على الجهاز والمتصفح نفسيهما. هذه نواتج مستهدفة، وليست مهارات ثبت اكتسابها.

العينة ثلاثة دروس: البرنامج والمدخلات والمخرجات؛ ترتيب الخطوات؛ المتغير الأول. تتضمن أمثلة للقراءة وتمارين بتصحيح محدود وخريطة تشرح ترتيب المهارات. تفضيل Python أو JavaScript يختار أمثلة، ولا يعد بمسار مكتمل أو بتشغيل كود أو شهادة. يمكن لجلسة الاختبار القصيرة أخذ عينة من الرحلة؛ لا يفترض إكمال الدروس الثلاثة خلالها.

## حالة التحقق
- تعريف افتراضي مبني على العقد والخطة ومواصفات التجربة؛ لم يُقابل متعلم لتأكيده.
- أُجريت مراجعة مكتبية مستقلة لنصوص `phase1/content/sample.json` وشيفرة عرض `phase1/web/app.mjs` في 2026-11-10؛ الملاحظات وحدودها في مصفوفة القبول. هذه قراءة للمصدر وليست تجربة متصفح أو دليل فهم المتعلم.
- تجربة مبتدئ بشري: **PENDING**. لا يدل إكمال المستندات أو فحوص الآلة على نجاحها.
