# تراكم المرحلة الثانية المقترح

هذا تخطيط فقط؛ لا يبدأ تنفيذ Backend أو حسابات ضمن المرحلة الأولى. المرحلة الثانية هنا هي الهيكل بعد بوابة عينة المرحلة الأولى وفق ترقيم العقد، وتقابل المرحلة 1 في جدول الخطة القديمة. الأولويات افتراضية وتُضبط بعد الأدلة.

## مستقل ويمكن تحضيره دون انتظار التجربة
| البند | التحضير القابل للمراجعة | شرط القبول المقترح |
|---|---|---|
| نموذج المحتوى والمهارة | تحديد مخططات وإصدارات الدرس والتمرين والمهارة وعلاقات المتطلبات وترحيلها | أمثلة صحيحة وأخرى مرفوضة ومراجعة التوافق مع العينة. |
| مواصفات محرك الخطة | أمثلة AND/OR، والبدائل والدورات والمراجع الناقصة والهدف غير المغطى وتغيير الهدف | حالات اختبار متوقعة توضح السبب والفجوات، دون احتساب البدائل كلها. |
| سياسة الأدلة والتقدم | تعريف الفرق بين محاولة وتمرين بمساعدة ودليل مستقل، وإصدار المحتوى | سيناريوهات تمنع تحويل إكمال الدرس إلى إتقان أو شهادة. |
| تصميم حفظ التقدم والإصدارات | تصور تخزين واستعادة محليين ومسودات وتعارضات وترحيل الإصدارات | معايير فقد البيانات وفحوص الاستعادة والفشل موثقة قبل التنفيذ. |
| مراجعة الإتاحة والخصوصية | إعداد حالات فحص لوحة المفاتيح والاتجاه والتكبير، وتحديد الحد الأدنى المتوقع للبيانات | قائمة فحوص قابلة للتنفيذ وقرارات معلّقة مسجلة دون ادعاء الامتثال. |
| مسار التأليف والمراجعة | تحديد حالات مسودة ومراجعة تقنية وتعليمية وإصدار | لا تظهر حالة منشور قبل أدلة المراجعة المقررة. |

## ينتظر نتائج تجربة العينة
| البند | القرار الذي يعتمد على الملاحظة | دليل يفتح العمل |
|---|---|---|
| صياغة البداية واختيار الهدف | تبسيط أو إعادة ترتيب الخطوات حسب التعثر الفعلي | ملاحظات البدء والمفردات من مبتدئ. |
| عرض سبب الترتيب | تعديل النص أو موضعه أو عرض الخريطة | هل وجده المشارك وشرحه بلغته دون تلقين؟ |
| الشرح والتمارين والتلميحات | تعديل المحتوى أو الأمثلة حسب مواضع الالتباس | محاولات وتمييز المساعدة عن الحل المستقل. |
| دلالة التقدم والاستئناف | تعديل التسمية ومكان الحالة حسب توقع المتعلم | ملاحظات العودة وما فهمه عن الحفظ المحلي. |
| أولويات الأجهزة والإتاحة | تحديد التجارب التالية بدل افتراض تمثيل جهاز واحد | بيئة الجلسة والعوائق الملحوظة واحتياجات المشاركين اللاحقين. |
| قرار عبور البوابة | معالجة العوائق الحرجة وتحديد الحاجة لجلسات إضافية | تجربة موثقة ومراجعة نتائجها؛ تجربة واحدة لا تثبت نجاحًا عامًا. |

التشغيل الحر المعزول والحسابات والمزامنة ميزات لاحقة تحتاج تصميمًا واختبارات خاصة وقرار نطاق؛ ليست جزءًا من عينة المرحلة الأولى ولا نتيجة متحققة الآن.
