## النتيجة الحالية

**تنفيذ العينة: مكتمل. التحقق التقني المحدد أدناه: PASSED. اعتماد فهم المبتدئ: PENDING.**

العينة تعمل محليًا بلا حزم خارجية أو حساب أو مفتاح API. تحتوي 3 دروس و9 تمارين و11 مصطلحًا، و4 مفاهيم مشتركة، وخيارات اتجاه تعلم وأمثلة Python/JavaScript، وخطة تشرح الترتيب وتظهر الأهداف المستقبلية كغير مكتملة.

## فحوص الآلة — PASSED

- `node scripts/check.mjs`: مطابقة عقد المحتوى، والمعرفات والإصدارات والخريطة، ووجود تمارين مستقلة وتلميحات وإجابات مناسبة، وصحة صياغة JavaScript، وفحص محدود لغياب eval/Function ومواضع HTML الخام في ملف الواجهة.
- `node --test --test-reporter=tap tests/*.test.mjs`: **24 ناجحًا، صفر فشل، صفر تخطٍّ**. السجل الكامل في `../test-results/unit-tests.tap`، ونتيجة فحص المحتوى في `../test-results/content-check.json`.
- 16 اختبارًا للخريطة: AND وOR المتداخلتان، اختيار بديل واحد، احترام تفضيل عند التعادل، نقل مهارة سابقة، نقص الدروس، الحالات sample/partial/planned/unavailable، رفض الدورات والمراجع الناقصة والتعبيرات الفارغة، وعدم تعديل المدخلات والتوافق مع المحتوى.
- 8 اختبارات للتقدم: الأرقام العربية والمسافات، رفض الإجابة الفارغة وعدم تفسير تعبير كود، عدم احتساب الخطأ كإكمال، تتبع المساعدة، الاستعادة والتحقق من إصدار البيانات، إعادة حساب الصحة المخزنة، وفشل/نجاح كتابة التخزين دون فقد الإجابة في الذاكرة.
- استجاب `GET /` و`GET /content/sample.json` بـ HTTP 200. لم تُفتح خدمة على الشبكة العامة؛ الاستماع إلى `127.0.0.1` فقط.
- شغّلت جلسة المحتوى أمثلة المؤلف الثابتة في Python وJavaScript، وراجعتها جلسة الدمج من حيث المعنى والتدرج؛ ليست هذه وظيفة تشغيل كود متعلم.

الفحص النصي لغياب مواضع خطرة ليس اختبار اختراق أو إثبات أمان شامل.

## عيوب رُصدت ثم صُححت

1. قوس زائد كشفه أول فحص syntax؛ صُحح ومر فحص JavaScript النهائي.
2. ازدحام بطاقات الاتجاه في العرض المتوسط؛ عُدّل ترتيبها إلى عمود مناسب.
3. رابط تجاوز التنقل كان يتداخل مع hash routing؛ أصبح يركز المحتوى دون تغيير الدرس، وأعيد فحصه بلوحة المفاتيح.
4. تبديل لغة المثال كان يبدل الهدف ضمنيًا؛ فُصل التفضيل عن الهدف وأعيد فحصه.
5. تلميح تدريب يوجه لنسخ الإجابة؛ أصبح يوجه لتحديد المدخل والمخرج دون نسخ مباشر.
6. شرح صياغة لغتين معًا؛ أضيف ترشيح لغة للقسم مع تبديل داخل درس المتغير.
7. رسالة «أحسنت الفهم» عند كل جواب صحيح؛ أصبحت «إجابة صحيحة» دون حكم أوسع.
8. عبارات الحفظ لا تواكب تعذر التخزين؛ أصبحت مرتبطة بنتيجة الكتابة، مع اختبار وحدة لفشل التخزين. لم يُحاكَ حظر تخزين حقيقي داخل المتصفح.

**FAILED حاليًا:** لا يوجد فشل مفتوح في الفحوص المنفذة. لا يشمل ذلك ما لم يُنفذ أدناه.

## PENDING / UNRUN / خارج النطاق

- **PENDING:** جلسة مع مبتدئ بشري وفق `PILOT_PROTOCOL.md`؛ قياس اكتشاف سبب الترتيب وفهم المفاهيم والمطلوب والنتيجة. لهذا لم تعتمد بوابة الفكرة تعليميًا بعد.
- **PENDING:** معايرة زمن كل درس وصعوبة التمارين بناءً على الملاحظة.
- **UNRUN:** قارئ شاشة فعلي، ومراجعة تباين شاملة، ومتصفحات/أجهزة فعلية أخرى، وتعارض استخدام تبويبات متزامنة، وحظر التخزين الفعلي في المتصفح، واختبارات ضغط أو اختراق.
- **خارج المرحلة الأولى:** PostgreSQL، الحسابات والصلاحيات، تشغيل كود متعلم وSandbox، المزامنة، المرشد AI، والنشر العام. لم تُنفذ أو تُختبر أو تُعلن ناجحة.

شغّلت المعاينة أثناء الفحص وأُوقفت عمليات الخادم المملوكة للفحص عند التسليم؛ تبقى ملفات التشغيل والعينة جاهزة. إعادة فتح أو تحديث رابط المعاينة تحتاج تشغيل الخادم وفق README.
