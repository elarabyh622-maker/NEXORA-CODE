# مسار — عينة المرحلة الأولى

تجربة محلية بالعربية من 3 دروس و9 تمارين وقاموس وخطة مترابطة. تختار اتجاهًا، تفهم سبب الترتيب، وتجيب تمارين مع تلميحات، ثم تعود إلى سجل تدريبك على الجهاز نفسه.

## التشغيل

المطلوب Node.js 22 أو أحدث؛ لا تحتاج تثبيت حزم أو حساب أو مفتاح API.

من PowerShell داخل هذا المجلد:

```powershell
node scripts/serve.mjs
```

ثم افتح [العينة المحلية](http://127.0.0.1:4173). يمكنك أيضًا تشغيل `Start-Masar.ps1` من PowerShell. لا تفتح `web/index.html` مباشرة لأن تحميل المحتوى يستخدم خادمًا محليًا. أوقفه بـ `Ctrl+C`.

إذا كان المنفذ مستخدمًا:

```powershell
node scripts/serve.mjs --port 4174
```

## الفحص

```powershell
node scripts/check.mjs
node --test tests/*.test.mjs
```

أوامر `npm start` و`npm run check` و`npm test` بدائل لنفس الأوامر؛ لا يلزم `npm install`.

## ما تحتويه العينة

- شاشة بداية باختيار الاستكشاف أو Python أو الويب، وخيارات مستقبلية موضحة.
- خطة من ثلاث خطوات، وسبب كل خطوة، وتوضيح نقص التغطية للأهداف المستقبلية.
- ما البرنامج والمدخلات والمخرجات؛ ثم ترتيب التعليمات؛ ثم أول متغير.
- أمثلة متكافئة في Python وJavaScript لقراءة الكود وتتبع الناتج.
- 9 تمارين مع تلميحات وتفسير للإجابة الصحيحة، ومنها مهام بسياق جديد.
- حفظ محلي للإجابات والمسودات والتفضيل والملاحظات، وتصدير سجل التدريب كـ JSON.
- قاموس مصطلحات، وتصميم عربي RTL وكود LTR واستجابة لأحجام الشاشة.

التصحيح قواعد لإجابات محدودة؛ لا يشغّل كود المستخدم ولا يقدّم حكمًا دلاليًا على شرح حر. كل البيانات والأجوبة متاحة داخل ملفات العينة، وليست منظومة امتحانات محمية. الحفظ خاص بالمتصفح والجهاز وليس حسابًا أو مزامنة، ومسح بيانات الموقع يمحوه. السجل تدريبي ولا يمثل إثبات إتقان أو شهادة.

## حدود المرحلة

هذا نموذج تجربة بلا Backend أو حسابات أو تشغيل حر للأكواد أو AI. اختيار HTML/CSS وJavaScript دون اعتماديات يخص العينة؛ التقنيات المستهدفة للمنتج تبقى موثقة في `../ARCHITECTURE.md`. بوابة قبول الفكرة تشمل تجربة مبتدئ حقيقية؛ تُسجل منفصلة عن الاختبارات الآلية.

اطلع على `docs/LEARNER_PROFILE.md` و`docs/PILOT_PROTOCOL.md` قبل التجربة، وعلى `docs/ACCEPTANCE_MATRIX.md` و`docs/VALIDATION_REPORT.md` لمعرفة ما فُحص فعلًا وما بقي معلقًا.
