# التحقق النهائي للمرحلة الثانية

**11 نوفمبر 2026 — التنفيذ التقني المحلي مكتمل.** التحقق النهائي على PostgreSQL `18.6` المحمول الحقيقي وقاعدة `masar_phase2_tests`، بحسابات اصطناعية مستقلة عن قاعدة التطوير.

| الفحص | النتيجة والدليل |
|---|---|
| بناء .NET Release وReact/TypeScript/Vite | PASSED؛ .NET بلا أخطاء أو تحذيرات، وASP.NET قدم الحزمة المبنية فعليًا. |
| منطق المنهج | **110/110**؛ [Domain TRX](../test-results/domain-final.trx). |
| واجهة وعميل API | **23/23**؛ `npm test`، بما فيها ربط CSRF بالهوية، تعارض المسودة واختيار الإصدار. |
| تكامل HTTP/PG | **13/13**؛ [التقرير](../test-results/http-integration.json). |
| صلاحيات قاعدة التطبيق | PASSED؛ [فحص PostgreSQL](../test-results/database-probe.json). لا superuser أو CREATE قاعدة أو دور أو جدول public أو كتابة سجل الترحيل. |
| عدم تراجع المرحلة الأولى | **24/24** مع نجاح فاحص العينة، من ملفات `phase1` دون تعديلها. |
| واجهة حقيقية | PASSED ضمن الفحص؛ [نتائج المتصفح](../test-results/browser-flow.json)، [سطح المكتب](../test-results/home-desktop.jpg)، [الموبايل](../test-results/lesson-mobile.jpg). |

شملت اختبارات HTTP: رفض الطلبات غير المصرح بها، CSRF، عزل الحسابات، مراجعات الخطط، تصحيح الخادم، تكرار المحاولة بالتزامن، إبطال الجلسة وقفل محاولات الدخول، وتفعيل الإصدارات. بعد إعادة تشغيل API اختبار مملوك بقيت الجلسة ومفتاح CSRF والخطة والمسودة قابلة للاستخدام. التقدم ممارسة موثقة فقط؛ لا إثبات إتقان.

| المراجعة | الإصلاح والدليل |
|---|---|
| P2-01، تبديل الحساب | طلبات الواجهة مرتبطة بهوية متحققة ومجال إلغاء، وCSRF يبلّغ هويته. رُفض رمز الحساب القديم عبر HTTP. في تبويبين فعليين لم تنتقل مسودة أ إلى ب؛ تقدم ب `0 / 9`، ورجع أ إلى `1 / 9` ومسودته المحفوظة. |
| P2-02، محتوى ناقص | حقول العرض تُفحص قبل تخزين المسودة. رُفض حذف الأهداف أو القاموس و`sections:null` والمثال غير المطابق في HTTP، مع بقاء العينة صالحة. |
| P2-03، تقاعد البداية | تفعيل إصدار منشور عملية صريحة ومقيدة بالإصدار والدور ومدونة. نجح تفعيل B وتقاعده واستعادة A دون تعديل خطة A. اختبارات الواجهة تثبت وجود اختيار حين يبقى منشور دون افتراضي. |

في المتصفح أُنشئت مراجعة خطة وحُفظت إجابة ومسودة. تعارض تبويبين أظهر النسختين، والحفظ الصريح أنتج النسخة 3 التي استُعيدت بعد إعادة التحميل. فُحص عرض الدرس عند 375px والبداية عند 1366px دون تمرير أفقي، وعُرض مثال JavaScript LTR داخل العربية RTL. هذا متصفح واحد بأحجام محاكاة.

قبل توقف حد الاستخدام نجحت **12/12** على Docker قبل الإصلاحات؛ الأدلة في `../test-results/docker-before-pause/`. بعد الاستئناف ظهر `Docker Desktop is unable to start` ولم يكتمل اتصال PostgreSQL عبر منفذه. **Docker BLOCKED حاليًا**، دون إعادة تشغيله أو تغيير بياناته. اشتغل بديل منفصل من [أرشيف EDB الرسمي](https://www.enterprisedb.com/download-postgresql-binaries) بعد حل مطالبة initdb والمسار العربي، وتم الفحص النهائي عليه. لا ترحيل بيانات بين المحركين.

- **FAILED مفتوح:** لا يوجد ضمن الفحوص المنفذة. فشل البناء المقيد بتدقيق NuGet عولج بالبناء مع وصول رسمي إلى NuGet؛ لم يُعطّل التدقيق.
- **PENDING:** تجربة مبتدئ بشرية للمرحلة الأولى.
- **UNRUN:** نشر عام وTLS إنتاجي فعلي، قارئات شاشة وأجهزة متعددة، اختبار تحميل أو تدقيق أمني شامل، واستعادة نسخة احتياطية كاملة. إدارة الإصدارات فُحصت عبر HTTP؛ لم تُنفذ رحلة نشر كاملة بالماوس.
- **خارج النطاق:** Sandbox وتشغيل كود المتعلم، AI، الدفع، ومنهج الإطلاق الكامل.
