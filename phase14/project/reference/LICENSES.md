# اعتمادات مشروع المخزون

أعدّت NEXORA CODE الشفرة التعليمية والعينة الخيالية المرفقة. يستخدم المشروع مكتبات .NET القياسية وأدوات بناء .NET 10 SDK. تثبّت أدوات .NET من Microsoft بشكل منفصل، وتعرض حزم التثبيت إشعارات الترخيص الخاصة بها. ملف ZIP يحتوي ملفات المصدر والاختبارات والعينة والدليل فقط. المشاريع الثلاثة تعتمد على ملفاتها المحلية ومكتبات إطار العمل، ولا تحتاج إلى حزم NuGet خارجية.
