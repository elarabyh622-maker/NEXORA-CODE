# كتالوج المنتجات بـReact وJavaScript

تدرّب على مكونات React والبحث ونماذج الإدارة محليًا. يعمل المشروع افتراضيًا بمصدر محاكاة في ذاكرة الصفحة. يعيد تحديث الصفحة المنتجات والجلسات التجريبية إلى البداية.

## التشغيل

ثبت Node.js 24.12 أو أحدث. جرى الفحص على Node.js 24.20.0. افتح PowerShell في المجلد الذي يحتوي `package.json` ثم نفذ الأوامر.

```powershell
npm.cmd ci
npm.cmd test
# افحص اختبارات قواعد البيانات ثم تابع
npm.cmd run dev
```

افتح `http://127.0.0.1:5173`. حسابا المحاكاة هما `admin` و`reader` وكلمة مرورهما `training`. تظهر هذه البيانات في وضع التدريب المحلي. تحفظ الجلسة في ذاكرة الصفحة. جرّب البحث باسم «دفتر» والتصنيف «قرطاسية»، واسمًا بلا نتائج، ثم امسح البحث والتصنيف وأرسل البحث مجددًا. بعد خطأ الاتصال تستطيع إعادة المحاولة بزر «بحث» حتى مع النص نفسه.

## تجربة الإدارة

1. ادخل بحساب التدريب المسؤول وأضف منتجًا بسعر 125 قرشًا ومخزون صفر.
2. عدّل المنتج ثم ألغِ تعديلًا آخر. افحص النتيجة قبل الحفظ وبعده.
3. افتح تأكيد الحذف وراجع اسم المنتج ثم أكد الحذف.
4. اخرج وادخل بالقارئ. تتاح القراءة ويختفي محرر الإدارة.
5. حدّث الصفحة لتتأكد من زوال الجلسة وعودة بيانات المحاكاة المبدئية.

## ربط خدمة المرحلة التاسعة

اختر مسار React مع Backend في المنصة لتحصل على ترتيب متطلبات الخدمة. استخدم نسخة تدريب من كتالوج المرحلة التاسعة وشغلها على `127.0.0.1:8000`، وأنشئ حساباتك عبر المطالبة المخفية الموضحة في دليلها. في نافذة PowerShell الخاصة بهذه الواجهة نفّذ الآتي قبل التشغيل.

```powershell
$env:VITE_DATA_SOURCE = 'api'
npm.cmd run dev
```

توجّه إعدادات Vite الطلبات النسبية `/api` إلى خدمة الكتالوج المحلية. في هذا الوضع أدخل الحسابات التي أنشأتها في Backend. تفرض الخدمة صلاحيات الكتابة في كل طلب وتحتفظ بالمنتجات في SQLite. يستخدم محوّل الاتصال `src/api.js` عقد المرحلة التاسعة ويتحقق من بيانات الاستجابة. يرجع الحذف والخروج 204 بلا جسم.

لبناء واجهة تعمل من أصل الخدمة نفسه نفذ `npm.cmd run build` بعد ضبط المتغير إلى `api`. انسخ **محتويات** `dist` إلى `catalogue/static` في نسخة تدريب مستقلة من مشروع Backend، ثم شغل الخدمة وافتح `http://127.0.0.1:8000`. يتحقق فحص التكامل من هذا الترتيب. للعودة إلى المحاكاة احذف متغير الجلسة الطرفية `VITE_DATA_SOURCE` ثم أعد تشغيل Vite أو البناء.

## قراءة المشروع

`src/App.jsx` يركب المكونات والنماذج. لحقلَي البحث حالة قابلة للتغيير قبل الإرسال، وتبقى الفلاتر المطبقة في حالة مستقلة. بعد الحفظ يُمسح البحث لإظهار المنتج. يدير `src/useProducts.js` التحميل والتنظيف وتجاهل الرد القديم، ويحدد `src/model.js` عقد المنتجات وقيمها. يحفظ `src/mock.js` المصدر التدريبي.

شغل `npm.cmd run build` قبل التسليم. اختبارات Node المرفقة تفحص الحراس والمصدر المحاكي ومحوّل API. تتطلب نقرات React وeffects فحص متصفح كذلك. لا تضع `node_modules` أو `dist` أو بيانات جلسات حقيقية في ملفات التسليم. يحتفظ `package-lock.json` بإصدارات الاعتمادات. راجع `LICENSES.md` لإشعارات الطرف الثالث.
