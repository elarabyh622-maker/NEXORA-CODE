# مشروع Go: خدمة مهام HTTP وJSON محلية

تدريب ببيانات خيالية ومكتبة Go القياسية فقط. تحتاج Go 1.26 أو أحدث؛ تحقّق بالأمر `go version`. لا تحتاج مكتبات خارجية أو قاعدة بيانات أو Python لتشغيل المشروع. البيانات في الذاكرة وتختفي عند إيقاف البرنامج. كل تشغيل يبدأ بقائمة فارغة، والحد الأقصى 100 مهمة. الخدمة للاستعمال التعليمي على جهازك، وتستمع إلى `127.0.0.1:8080` فقط؛ لا تغيّر العنوان إلى عنوان عام.

## البناء والتشغيل

بعد فك ZIP افتح PowerShell داخل المجلد الذي يحتوي `go.mod`. الأوامر تعمل في Windows PowerShell 5.1 وPowerShell 7:

```powershell
go version
go build .
go run .
```

نفّذ كل أمر بعد نجاح السابق فقط. افحص `$LASTEXITCODE` بعد البناء؛ يجب أن يكون صفرًا. يطبع التشغيل عنوان الخدمة ثم ينتظر الطلبات. اترك هذه النافذة مفتوحة، وافتح نافذة PowerShell ثانية لتجربة الطلبات. استخدم Ctrl+C لإيقاف الخدمة. إذا كان المنفذ مشغولًا يفشل التشغيل؛ لا توقف برنامجًا آخر عشوائيًا.

```powershell
Invoke-RestMethod -Uri 'http://127.0.0.1:8080/tasks' -Method Get
Invoke-RestMethod -Uri 'http://127.0.0.1:8080/tasks' -Method Post -ContentType 'application/json' -Body '{"title":"Learn Go"}'
Invoke-RestMethod -Uri 'http://127.0.0.1:8080/tasks/1/complete' -Method Post
Invoke-RestMethod -Uri 'http://127.0.0.1:8080/tasks' -Method Get
```

يعرض PowerShell استجابة JSON ككائنات؛ القائمة الفارغة قد لا تطبع شيئًا. لرؤية النص الخام استخدم `(Invoke-WebRequest -UseBasicParsing -Uri 'http://127.0.0.1:8080/tasks').Content`. ترمي أدوات PowerShell خطأ عند استجابة 4xx أو 5xx؛ هذا متوقع عند تجربة مدخلات مرفوضة أو المهمة غير المكتملة.

## العقد

| الطلب | النجاح |
| --- | --- |
| `GET /tasks` | `200` وقائمة JSON مرتبة حسب الإنشاء؛ تبدأ بـ `[]` |
| `POST /tasks` مع `{"title":"Learn Go"}` | `201` و`{"id":1,"title":"Learn Go","completed":false}` |
| `POST /tasks/1/complete` دون جسم | `200` والمهمة نفسها مع `"completed":true` |

كل الأخطاء JSON بالشكل `{"error":"message"}`. العنوان من 1 إلى 120 محرف Unicode، دون مسافات زائدة في الطرفين أو محارف تحكم. الجسم بحد أقصى 4096 بايت. الحقول غير المعروفة وJSON التالف أو أكثر من قيمة JSON مرفوضة. المعرّف رقم صحيح موجب بصيغته العادية مثل `1`؛ لا تقبل `01` أو `+1`. لا يمكن تعديل عنوان مهمة أو حذفها في هذا التدريب.

الحالات: `400` مدخل غير صالح، `404` مسار أو مهمة غير موجودة، `405` طريقة HTTP غير مسموحة، `409` مهمة مكتملة بالفعل أو امتلاء حد المهام، `413` جسم أكبر من الحد، `501` الدالة التدريبية لم تكتمل. الأخطاء لا تعدّل المهام. تستخدم عمليات القراءة والإنشاء والإكمال mutex واحدًا لمنع تضارب الطلبات المتزامنة؛ وتعيد القائمة نسخة لحماية الحالة الداخلية.

## المهمة الوحيدة

أكمل `func (s *Store) complete(id int) (Task, error)` في `complete.go` فقط. نسخة البداية تعيد `Task{}, ErrIncomplete` دون تعديل؛ لذلك يرجع طلب الإكمال `501` حتى تنفّذ الحل.

1. اقفل `s.mu` باستخدام `Lock` وأجّل `Unlock` باستخدام `defer` قبل لمس `s.tasks`.
2. استدعِ `taskIndex(s.tasks, id)`، وأعد `Task{}, err` إذا فشل البحث. الدالة ترفض المعرّف غير الموجب بـ `ErrInvalid`، وغير الموجود بـ `ErrNotFound`.
3. إذا كانت `s.tasks[index].Completed` تساوي `true`، أعد `Task{}, ErrCompleted` دون تغيير.
4. غيّر `Completed` للمهمة المطلوبة فقط إلى `true`، ثم أعد المهمة و`nil`.

لا تنقل القفل إلى معالج HTTP؛ قد يستخدم المتجر مستدعون آخرون. لا تضف ملف بيانات أو اتصال شبكة أو goroutine داخل الدالة. `main.go` مسؤول عن HTTP وتحويل الأخطاء إلى رموز حالة، و`store.go` مسؤول عن البيانات والتحقق من العنوان.

## الاختبارات

الاختبارات تستخدم `httptest`؛ معظمها في الذاكرة، واختبار رحلة HTTP واحد يفتح منفذ loopback مؤقتًا ويغلقه تلقائيًا. لا تصل الاختبارات إلى الإنترنت. تشمل JSON والقائمة والإنشاء والمدخلات المرفوضة وحدود الجسم والسعة ونسخ الحالة والطلبات المتزامنة.

قبل الحل:

```powershell
go test ./... -args -starter
go test ./...
```

يجب أن ينجح الأمر الأول؛ فهو يتوقع `501` من الإكمال ويتحقق من عدم تعديل الحالة. الأمر الثاني يجب أن يفشل لأن الإكمال غير منفّذ. نجاح الهيكل لا يعني إكمال المشروع.

بعد إكمال `complete.go`:

```powershell
go build .
go test ./...
```

يجب أن ينجح البناء والاختبارات الكاملة ويكون `$LASTEXITCODE` صفرًا بعد كل أمر. لا تستخدم `-starter` بعد الحل لأنه يتوقع الرفض. يمكن تشغيل `go test -race ./...` إذا كان Go race detector وأدوات C المتوافقة مثبتة؛ هذا فحص إضافي وليس شرط تشغيل على Windows. نجاح اختبار التزامن العادي وحده لا يساوي فحص race detector.
