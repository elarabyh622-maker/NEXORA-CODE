## تشغيل المشروع

بعد تفعيل الوصول، نزّل `go-tasks-api-starter-v1.zip` من درس المشروع. فكّه ثم شغّل `go run .` من مجلد المشروع باستخدام Go 1.26 أو أحدث. يستمع البرنامج على `127.0.0.1:8080` ويحتفظ بالمهام في الذاكرة أثناء التشغيل. أكمل دالة `complete` ثم شغّل اختبارات Go. [دليل المشروع والأوامر](project/reference/README.md) · [تجهيز Go](https://go.dev/doc/tutorial/getting-started) · [مرجع اختبارات HTTP](https://pkg.go.dev/net/http/httptest)

**السعر المقترح للمسار 799 جنيه مصري**. يجمع المسار أساسيات اللغة مع بناء خدمة HTTP واختبارها. يُضبط سعر البيع من لوحة الإدارة.

## بناء الحزمة وفحصها

شغّل من جذر المستودع بعد تجهيز Python وGo 1.26 أو أحدث. مرّر `--go` مع مسار `go.exe` إذا لم يكن الأمر متاحًا عبر `PATH`.

```powershell
python -B phase18/build_curriculum.py
python -B phase18/build_curriculum.py --check
```

يقارن الفحص الحزمة بمصادرها، ويترجم أمثلة Go المعتمدة ويشغّلها في مجلدات مؤقتة، ويطابق أرشيف البداية مع مصادره. يفحص [اختبار الإصدار](check-release.py) ترقية المنهج على PostgreSQL مؤقت، وبقاء خطة الإصدار السابق، وتصحيح التمارين، وصلاحيات عرض الدرس وتنزيل المشروع.

يضم `phase18-ar-v1` إجمالًا 197 درسًا و565 تمرينًا و25 هدفًا و48 مختبر كونسول. تعمل أمثلة Go وخدمة المشروع على جهاز المتعلم.
