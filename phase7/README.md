# المرحلة السابعة — تحليل البيانات بـPython

يضيف الإصدار `phase7-ar-v1` ثمانية دروس و22 تمرينًا مصححًا وعشرة معامل Python. يبدأ المسار بقراءة CSV والتحقق من العناوين وتنظيف الصفوف، ثم ينتقل إلى التجميع وحساب النسب وكتابة تقرير. يستخدم المشروع الختامي سجلات تدريبية خيالية ويطلب من المتعلم توثيق أثر الصفوف المستبعدة وشرح حدود الاستنتاج من العينة.

تضم خطة المتعلم الجديد 32 درسًا مرتبة حسب المتطلبات. يدرس 12 درس أساسيات، ثم 12 درس Python، ثم 8 دروس تحليل بيانات. يحتوي الإصدار الكامل على 44 درسًا و118 تمرينًا مصححًا وأربعة مسارات. تبقى الخطة المحفوظة مرتبطة بإصدارها، ويمكن الرجوع إليها من سجل الخطط.

## الحزمة والتحقق

```powershell
python -B phase7/build_curriculum.py
python -B phase7/validate-data-path.py
```

يتحقق البناء من بصمة حزمة المرحلة الرابعة ويضيف مسار البيانات إلى نسخة جديدة. يقرأ الخادم حزمة `dist/curriculum.json`، وتبقى حلول المعامل في مصادر التأليف. تخفي واجهة المتعلم مفاتيح الإجابات وحالات التقييم الخاصة.

بصمة SHA-256 للحزمة المختبرة: `a66ba6f564d7ce49bbab3afa7aeb7d69452589e1b68a4e315d9da807583000cc`.

- اجتاز الاختبار المحلي 46 حالة Python تشمل الأمثلة والحلول المرجعية وحالتين إضافيتين للمشروع.
- اجتازت اختبارات المنهج على .NET الحالات الـ110.
- تحقّق PostgreSQL المعزول من الانتقال من المرحلة الرابعة إلى السابعة، وإعادة طلب التفعيل، وبقاء الإصدار السابق والخطة المحفوظة، وترتيب المسارات الأربعة وتصحيح أسئلة المسار الجديد.
- تحقق Edge على قاعدة الاختبار من ظهور مسار البيانات، وترتيب 32 درسًا، وفتح مثال Python، والرجوع إلى نفس الخطة، وظهور مختبر المشروع.
- اجتاز تقييم المشروع الختامي أربع حالات عبر gVisor وسجّل دليل مهارة في PostgreSQL، باستخدام نسخة مطابقة لخادم المتعلمين على قاعدة اختبار معزولة. في فحص المضيف قبل التقييم نجح تنفيذ Python وNode.js، وانتهت مهلة اختبار منفصل لمسار خطأ Python. لم يُعد تشغيل مجموعة فحوص المضيف كاملة بعد نجاح المشروع.

اختبارات التطوير موجودة في [الفحص الشامل](check-release.py) و[فحص الواجهة](check-browser.cjs). تستخدم قاعدة الاختبار `phase7_checks` على `55437` وخادم التطبيق على `5197`. يحتاج الفحص الشامل قاعدة اختبار يبدأ إصدارها النشط من المرحلة الرابعة. لا تشغّل الفحص على بيانات المتعلمين.
